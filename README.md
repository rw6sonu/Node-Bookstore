To create a web-based Book Store Management System using Node.js and Express.js that allows users to manage book records efficiently. The system will use MongoDB database for data storage, EJS for frontend rendering, Multer for book image upload, and implement full CRUD operations for managing books.


📚 Add New Book
Create a form where user can enter book details:
Book Title
Author Name
Category
Price
Quantity
Description
Book Cover Image


View All Books
Display all books stored in database in table or card format.
Show:
Book Image
Book Title
Author
Category
Price

✏️ Update Book Details
Allow user to edit existing book information:
Change title
Update price
Modify quantity
Replace image if needed


❌ Delete Book
Provide delete button to remove book record permanently from database.
Use book ID to delete selected record.


🖼️ Image Upload Management
Use Multer middleware for:
Uploading book cover
Saving image path in database
Displaying uploaded image in frontend


✅ Final Book Store Summary
System should provide:
Total books available
Book details management
Image display
